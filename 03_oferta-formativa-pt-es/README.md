# Bloco 3 — Normalização da oferta formativa do ensino superior (Portugal e Espanha)

> **Secção do relatório:** 4.3

Tarefa interna n.º 1465, executada em três entregas: levantamento e normalização de 16 140 cursos de 182 instituições dos dois países a partir de fontes oficiais, com definição prévia de uma estrutura de dados comum e documentação de equivalências entre sistemas de ensino não coincidentes, e síntese comparativa em apresentação.

**Nota:** os ficheiros das fases de Portugal (C.6) e Espanha (C.7) não foram incluídos nesta versão do repositório — ver os README das respetivas pastas.
