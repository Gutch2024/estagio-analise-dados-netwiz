# C.20 — Transferibilidade do método a 20 agências imobiliárias

> **Anexo do relatório:** C.20 · **Secção:** 4.6.4 · **Entidade:** NetWiz Systems / Instituto Piaget

## Objetivo
Aplicar o método das tarefas P1–P3 a agências de mediação imobiliária independentes, verificando se os critérios se mantêm válidos num setor não previsto.

## Contexto
Pedido do orientador, tratado à parte por o setor imobiliário não constar dos oito setores da C.4.

## Ficheiros nesta pasta
- **`NetWiz_Imobiliario_P1_Independentes.xlsx`** — Base de leads das 20 agências independentes (P1).
- **`NetWiz_Imobiliario_P2_Scorecard.xlsx`** — Scorecard de maturidade digital com os mesmos critérios ponderados (P2).
- **`NetWiz_Imobiliario_P3_Produtos.xlsx`** — Análise de encaixe nos produtos próprios (P3).

## Ferramentas utilizadas
Microsoft Excel; fontes públicas das tarefas anteriores mais o IMPIC; Claude e conectores.

## Competências demonstradas
Consistência metodológica; transferência de um método validado para um contexto novo sem perder comparabilidade.

**Unidades curriculares relacionadas:** Análise de dados.

## Resultado
20 agências independentes com maturidade média de 47,5 (face a 70,3 das grandes redes); sem encaixe no Course Match e apenas seis com dimensão para o TalentHub.
